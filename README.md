## 📌 О проекте

**CineMatch** — современный веб-сервис для быстрого и умного подбора фильмов на вечер. Проект решает проблему бесконечного поиска кино, предлагая персонализированные рекомендации на основе:
- 15+ жанров (включая **Ужасы**, Фантастику, Триллеры, Мистику, Фэнтези, Детективы, Комедии и др.);
- Текущего настроения и вайба (Леденящий ужас, Взрыв мозга, С друзьями под попкорн, Уютный вечер под пледом);
- Эпохи выхода (Новинки 2020–2026, Золотая эра 2000–2019, Ретро-классика);
- Фильтра минимального рейтинга (от 7.0+ до 8.8+);
- Экспресс-квиза за 60 секунд.

Каждый фильм в каталоге оформлен кинематографической HD-обложкой, рейтингом Кинопоиска/IMDb, описанием, знаменитой цитатой и списком актёров в модальном окне.

## 🚀 Как запустить проект

### 1. Локально на компьютере
Просто откройте файл `index.html` в любом современном веб-браузере (Chrome, Edge, Firefox, Safari) или запустите локальный сервер:
```bash
python -m http.server 8080
```
И перейдите по адресу: `http://localhost:8080`

### 2. Хостинг на GitHub Pages
1. Создайте репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`
3. В настройках репозитория (**Settings**) перейдите во вкладку **Pages**.
4. В разделе **Build and deployment -> Branch** выберите ветку `main` и нажмите **Save**.
5. Сайт будет опубликован бесплатно по адресу:
   `https://<ваш-логин-github>.github.io/<имя-репозитория>/`

- **HTML5:** Семантическая вёрстка, разметка мета-данных.
